# Melee for New Nintendo 3DS

An experimental native ARM port of Super Smash Bros. Melee with original
gameplay, CPU matches, music, native stereoscopic 3D, and 4:3/expanded display
modes. **Playable on New 3DS; stable 60 FPS has not been achieved.**

**[Build, install, controls and current limitations → native-3ds/README.md](native-3ds/README.md)**

The `3ds` branch contains the port through update 9 in `native-3ds/`.
Bring your own US v1.02 disc dump. This repository distributes source and build
tools, with no ISO, game assets, firmware or prebuilt game package.

This is a fork of [doldecomp/melee](https://github.com/doldecomp/melee).
Its decompilation source and history are preserved, and port compatibility
changes are generated as overlays. The port pins upstream commit
`039c4bf4ca33338c35d21901ad19b7ede19d19ad`.
