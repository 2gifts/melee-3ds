# Group play: Versus with nearby consoles

Play Versus with up to **four New 3DS consoles in the same room**, each player on their own console. Group play uses
the 3DS's local wireless, like Download Play or local multiplayer in retail games: **no internet, no account and no
router.**

Group play is part of both regular builds (everything unlocked and fresh save), and the two can play together.

## What you need

- Two to four **New 3DS** consoles, each with Melee for New 3DS installed (either build).
- **Wireless communication turned on** on every console (the wireless switch on older models, or the HOME Menu
  settings).
- Every console on the **same version** of the game. Build them from the same release.

## Host a game

1. Choose **VS Mode → Melee → Group**. The top screen says **Choose a game.** and the console starts looking for
   games nearby (press **B** there to go back).
2. On the bottom screen, tap **HOST GAME**.

Your console opens the lobby (the character select screen) and other consoles can now find your game.

## Join a game

1. Choose **VS Mode → Melee → Group**.
2. The **Available Games** list shows the games nearby: the host's name and Mii, and a stock icon for each fighter
   already in the lobby. When more games are found than fit, use the arrows beside the page number.
3. Tap a game to join it.

You land in the host's lobby. To play on your own instead, press **B** to go back and choose **Solo**.

## The lobby

The lobby is Melee's character select screen, shared by every console. The four doors are the four ports: **port 1 is
the host**, and each console that joins takes the next free port.

- **Pick your fighter, costume and name tag** as usual.
- **Anyone can add a CPU** or close a door, including doors no console sits in. A door that someone else is using (a
  slider, the name tag list, name entry) can't be changed until they finish.
- **Only the host sets the rules** (stocks, time, items, Teams, handicap). The other consoles show the host's rules on
  their bottom screen.
- The bottom screen shows who is connected, each console's **signal strength**, and what each player is doing.
  A short message appears when someone joins or leaves.
- Each player's name (their Mii name, or the console's name) is shown under their door and above their damage in the
  match.
- Moving the **C-stick** turns the character select camera on every console, just for fun.
- **Start** works on any console once every door in use has a fighter. It is disabled while the host is in the rules
  menu.

### The stage select

The host's **Stage Selection** rule (Rules → Additional Rules) decides who picks, as on one console:

- **Any:** any player can pick, and the first pick counts for everyone.
- **Turns** and **Loser:** one player picks (taking turns, or the loser of the last match). Only that player's console
  has a cursor; the bottom screen of the others says who **PICKS THE STAGE**. If that player leaves, the pick passes
  to the next player.
- **Random** and **Ordered:** the host's console chooses the stage, and nobody picks.

The **Random** icon picks from the **host's** save, whoever presses it: the host's Random Stage Switch, the stages the
host has unlocked, and the host's recent picks. Your console shows "Now loading" until the match starts.

If a stage your save hasn't unlocked yet is chosen, your console shows "Now loading" without revealing the stage, and
you play on it anyway. Fighters you haven't unlocked work the same way.

## Matches

Every console runs the same match in step. The game waits for the slowest console, so if one console slows down
(for example four fighters on a large stage), everyone slows down with it.

- **Sudden death** and **Teams** work as usual.
- If a player's console disconnects or leaves during a match, **their fighter becomes a CPU** and the match goes on.
- After the match, every console shows **"The winner is..."** and the results together, with each player's name under
  their window. The results move on when every player has pressed through them. Then everyone returns to the lobby
  for the next match.
- Stars and auto handicap work as in normal Versus.
- If the match earned something on your save (a new stage, a trophy, a message like "You played 1000 VS matches"),
  your console shows it after the results, as in normal Versus. Meanwhile the other consoles show you as **VIEWING A
  PRIZE**, and the next match waits for you.

## Joining during a match

You can join a game whose match has already started. Your bottom screen then shows the **match in progress**: the
timer, and each player's stocks and damage. You join the lobby when the match ends.

## Leaving

- **Hold B on the character select screen** to leave the lobby. You are back on **Choose a game.** with the list of
  games open (Back from Solo's character select returns to the Solo / Group menu, with Solo highlighted). If you are
  the host and other players are there, a message asks **End the session?** first: choose **Yes** or **No** (No is
  highlighted; B is No). While it is up, nobody can start a match, and the other consoles show you as **ANSWERING A
  PROMPT**.
- **L+R+Start** (the soft reset) never leaves the group behind: in the lobby it works like holding B (the host is asked
  first), on the stage select it takes everyone back to the character select (from any console), and on **Choose a game.** it goes to the main menu
  and closes the session.
- If your save has earned a hidden fighter, **"A new challenger approaches!"** starts when you leave the lobby (or when
  the session ends), as it would after a Versus match on one console. Beat the challenger to unlock it.
- **When the host leaves, the session ends for everyone.** The other consoles go back to **Choose a game.**, where a
  message says why the session ended (the host left, stopped responding, and so on). The list of games is already
  open underneath: press **A** to close the message, or tap a game to join it straight away.
- If a console loses the connection, it shows the reason the same way.

## Your save

Each console uses its own save. Nobody else's progress is copied to yours, and your unlocks don't change.

Group matches count on your save as Versus matches on one console do:

- your **total VS matches and play time**;
- the **VS Records** (Data → VS Records): every fighter in the match, and your own name tag. Other players' name tags
  belong to their saves, so KOs against them aren't credited to a tag of yours;
- **stage unlocks, trophies and special messages**, shown after the results;
- **hidden fighters**: their "new challenger" fight comes when you leave the lobby rather than after the match, so the
  others don't wait for it. Unlike one console, any message or trophy the match earned is shown right away, even when
  a challenger is due.

## Good to know

- **The HOME button is off** while you are in a group (browsing, the lobby, a match or its results). Pressing it shows
  "HOME IS UNAVAILABLE DURING WIRELESS PLAY". Leave the group to use HOME.
- **Closing the lid doesn't put the console to sleep** while you are in a group, so nobody gets disconnected. It sleeps
  normally again once you leave.
- Keep the consoles close together. Walls and distance weaken the signal; the bars on the bottom screen show how good
  each connection is.

## Known limitations

- **The game freezes briefly while it draws Miis.** Each Mii head on the Available Games list (and your own, on the
  HOST GAME button) is drawn the first time it is shown. While it is being drawn, the whole game stops for a moment:
  both screens freeze, the buttons on screen don't respond, and the music pauses. You notice it most when you open
  the list and several Miis are drawn one after another, but it also happens when a new game appears, when you turn
  to a page you haven't seen yet, and when you come back to the list a while after leaving it. Wait for the Miis to
  appear before tapping. Games without a Mii show the Smash emblem and cause no freeze.
- **The stage select cursor has no player label.** When one player picks the stage (Stage Selection Turns or Loser),
  the cursor should show that player's port ("P1", "P2"...), but it is always a plain white ring. The other consoles'
  bottom screens still say who **PICKS THE STAGE**. This also happens in solo Versus.

## Troubleshooting

| Problem | What to do |
|---|---|
| "Please enable wireless and try again" | Turn on wireless communication (the switch, or the HOME Menu settings), then choose Group again |
| The host's game doesn't appear | Make sure the host tapped HOST GAME and is on the character select screen; move closer; check both consoles run the same version |
| A game says FULL | Four consoles are already in it. Wait for someone to leave, or host your own game |
| The session ends during play | The host left or lost the connection. Move closer and host again |
| No Mii next to a name | The console has no Mii set up (or it couldn't be read). The game shows the Smash emblem instead |

To report a problem, include `SD:/3ds/melee/game.log` from **every** console in the session, copied right after it
happened, and the steps that led to it. See [Reporting problems](../../README.md#reporting-problems).
